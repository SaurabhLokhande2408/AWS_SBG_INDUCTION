# AWS SBG RMDSSOE Static Website

A high-performance, dark-themed React + Vite landing page for AWS Student Builder Group at RMDSSOE.

## Quick Start
1. Run `npm install`
2. Run `npm run dev` to preview locally.
3. Run `npm run build` to create static production distribution.

## Deploying to Vercel
Push this repository to GitHub and import it on Vercel. Framework preset will automatically detect Vite.
